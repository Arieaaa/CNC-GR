# 8 号数据分析与交接材料

> 状态更新：1 号已确定本次正式服务达标率留空，7 号已完成核查并补充诊断。请优先使用 [v1.0 统计与诊断](../analysis_2026-11-11_v1.0/README.md)；本目录保留为历史版本。

本目录记录 A、B、C 实验的正式统计和 7 号抽样复现结果。正式统计为 24 轮、8 个配置，每配置 3 轮；A、B、C 各有 1 次复跑，作为单独的复现证据。

- [分析结果与汇报要点](8号分析结果与汇报要点_v0.2_2026-11-11.md)
- [正式统计与复现核查工作簿](8号实验统计与复现核查_v0.2.xlsx)
- [与 7 号核对统计结果](8号统计结果与7号核对_v0.3_2026-11-11.md)
- [与 1 号确认数据标准](8号数据标准与1号确认_v0.3_2026-11-11.md)
- [抽样复现对照](8号抽样复现对照_v0.2.csv)
- [C 组 FIFO 逐秒丢包图](C_FIFO_逐秒丢包.png) 和 [逐秒数据](C_FIFO_逐秒丢包.csv)

三张正式统计图位于同级目录 `../analysis_2026-11-11/figures/`。历史报告的来源和窗口说明见报告；本次汇报的最新判定状态及补充诊断以 v1.0 为准。

`compare_reruns.py` 读取 7 号提供的原始交接 ZIP，并核验 ZIP 的 SHA-256；仓库中的解压文件不能直接作为此脚本的 ZIP 参数。绘图脚本 `plot_c_fifo_loss.py` 支持从已核验计数生成逐秒图，也支持从归档复算；在非 Windows 环境需要指定可用中文字体。
