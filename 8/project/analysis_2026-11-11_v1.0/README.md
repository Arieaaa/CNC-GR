# 8 号实验统计 v1.0

根据 1 号提供的《CNC-GR 实验统计与汇报口径 v1.0》和 7 号核查答复更新。正式样本仍为 24 轮、8 个配置。**本次正式服务达标率留空**，不把示例阈值作为判定标准。原有复跑、B 路线 pilot 与 C 的 6 轮交错诊断另列，不并入正式统计。

- [正式统计与诊断说明](8号正式统计与诊断说明_v1.0_2026-11-11.md)：按配置展示逐轮值、有效轮数、均值和样本标准差，补充 A/B/C 的最新核查与局限。
- [正式统计与诊断工作簿](8号实验统计与诊断_v1.0.xlsx)：包括原正式数据、抽样复现、统一口径和 C 交错诊断。
- [正式逐轮与统计表](tables/正式实验逐轮与统计.csv)：报告中 40 行正式指标及统计结果。
- [正式逐轮指标](inputs/formal_run_metrics.csv) 和 [正式运行索引](inputs/formal_runs.csv)：保留运行 ID、来源和各指标窗口，A 的窗口已更正。
- [C 交错诊断原始汇总快照](inputs/C交错复测_20261111.csv)：来自 7 号仓库记录，不属于正式样本。
- [图表目录](figures/)：正式图和单列的诊断补充图。
- [生成脚本](generate_report.py)：从本目录数据快照生成报告和正式逐轮统计表；需要 Python 标准库。

P95 以正式汇总表原值为准；原始样本的独立复算使用最近秩并注明差异。工作簿的正式统计公式依赖「逐次指标」的原始行序，请使用筛选，避免排序后保存。统计数字仍需 7 号复核，配置和解释由 2 号核对。PPT 尚未更新。
