# 8 号正式样本与诊断图说明

正式图涵盖 A、B、C 各配置原有 3 轮。圆点为逐轮记录，菱形和误差线为 3 个逐轮结果的均值 ± 样本标准差；每个配置有效样本数 n=3。额外复跑和诊断轮不并入正式样本。A、B、C 的原正式来源分别为 [4 号汇总](https://github.com/Arieaaa/CNC-GR/blob/65e4e94f447a485de9c8217b094fe414d74cab06/4/project/expA_summary.csv)、[5 号汇总](https://github.com/Arieaaa/CNC-GR/blob/65e4e94f447a485de9c8217b094fe414d74cab06/5/project/实验B/实测/summary.csv)、[6 号汇总](https://github.com/Arieaaa/CNC-GR/blob/65e4e94f447a485de9c8217b094fe414d74cab06/6/project/wifi-qos/results/formal_runs.csv)。

- **A_正式_TCP与RTT.png**：四组依次为 4、8、12 台且信道 1/6，及 12 台信道 1/1。TCP 总量是各终端接收吞吐的加和，流间窗口未严格对齐；P95 图为每轮取各终端 P95 的最大值，再跨轮汇总。TCP 和 ping 同一分轮，UDP 为另一分轮。iperf3 预热 10 秒后计量 60 秒，ping 采集约 60 秒、未去预热。
- **A_正式_UDP丢包与抖动.png**：同一四组配置。丢包率分别展示每轮各终端的平均值和最大值，抖动展示每轮各终端的最大值。所有图表单位均在纵轴中标出。
- **B_移动与关联.png**：SSF 与 LLF 各 3 轮，相同路线（15 m 至 70 m、1 m/s）、信道 1/6 和三条 256 kbit/s UDP 背景流。P95 为全轮成功应答，切换附近间隔包括正常探测周期，不等同于精确协议切换时间。原正式路线存在信号正值异常，偏移路线 pilot 是单独诊断，未替换正式样本。
- **C_混合业务与QoS.png**：共享 FIFO 与分类 HTB 各 3 轮，服务器出口上限 2 Mbit/s，300 kbit/s UDP 与后台 TCP；60 秒正式运行取后 50 秒。RTT P95 仅含成功应答，UDP 丢包与 ping 缺失分别统计。
- **C_交错诊断_实时UDP与队列.png**：7 号在相同出口上限与负载下交错做的共享 FIFO 与分类 QoS 各 3 轮额外诊断。左图 UDP 丢包率取接收端后 50 秒，右图队列累计丢包数覆盖整轮全部业务，两者窗口和对象不同。右图不支持“QoS 所有业务零丢包”。[7 号诊断表](https://github.com/Arieaaa/CNC-GR/blob/65e4e94f447a485de9c8217b094fe414d74cab06/7/project/诊断试验/C交错复测_20261111.csv)。
