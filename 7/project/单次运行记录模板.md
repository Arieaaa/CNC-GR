# 单次运行记录模板 v0.1

每次独立运行复制一份，包含失败、试跑和复现。请保留空字段和缺失说明；不填虚构值。示例目录名 `expA_n12_ch1-6_run01` 仅说明格式。

## 1. 基本信息

| 项目 | 填写 |
|---|---|
| 运行 ID `run_id` / 实验 A、B、C / 类型（试跑、正式、复现） | |
| 配置 ID / 对照臂或策略 / 重复编号 | |
| 操作者 / UTC 实际开始与结束时间 / 最终状态 | |
| 复现对应的原运行 ID；失败或中止原因 | |
| 实验脚本版本 / 公共拓扑版本 / 相关工具版本 / 系统及内核 | |
| 原始目录及配置、状态、日志索引；整理结果存放处 | |
| 时间来源、对时方式、偏差或不确定性 | |
| 正式运行预约及与 3 号确认的入口 | |

## 2. 共用配置和统计窗口

| 项目 | 填写 |

| 稳态统计窗口相对运行起点的起止 s / 预热 / B 组事件对齐 | |
| AP 与终端实际位置、关联及 BSSID（可写文件路径） | |

## 3. 按实验填写

### A：并发与信道（不适用则留空）

- 终端分档、信道组合、位置和关联：
- 吞吐测试及定速 UDP 丢包测试是否分轮、各自运行 ID：
- 各终端速率、方向、时长；并发服务进程/端口或并发能力验证记录：
- 连接失败、服务端拒绝和日志位置：

### B：移动与关联（不适用则留空）

- SSF / LLF 策略及实际生效证据：
- 路线、位置与时间、背景终端数量及负载：
- AP/BSSID、关联数、模型信号来源及采样周期：
- 连续探测日志、周期、超时及时间基准：
- 切换是否实际发生；前后两次成功探测时间及期间失败记录：

### C：混合业务与 QoS（不适用则留空）

- 默认队列 / `tc` 分类与 HTB；实际出口接口及路径验证：
- 两臂聚合带宽上限、各流设定与端口；拥塞条件：
- 队列规则及前后计数路径、命中情况：
- UDP 发送/接收日志、抖动和丢包；TCP 接收吞吐与 RTT 日志：

## 4. 检查、异常与交付

| 检查项 | 记录 |
|---|---|
| 原始文件及状态是否完整、可读；未采到什么 | |
| 时间与单位是否可对齐；对照项是否一致 | |
| 必要指标的来源、统计窗口、缺失及异常 | |
| 是否列入正式分析；原因及待处理事项（未确认前填待定） | |
| 若为复现：脚本/参数差异、关键指标差异及日志路径 | |
| 检查人、日期 / 交给 8 号的版本和位置 | |

采集结束后对照[异常检查清单](异常检查清单.md)。正式配置至少重复 3 次，不得覆盖上一次目录；3 号与 7 号从 A、B、C 各抽至少一个正式配置复现。
