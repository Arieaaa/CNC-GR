# 07 号日志采集和基础验收整理

需要 Windows 的 Python 3、OpenSSH `ssh` 和 `scp`，无需安装 Python 第三方库。在 PowerShell 进入本包目录执行下列命令。脚本不包含或保存登录密码；SSH 会按需交互提示，采集时可能需要输入多次。

## 下载一次已结束的运行

```powershell
python .\脚本\采集日志.py smoke_20261107T101304Z_rriph1zz --host 实验机地址 --known-hosts 已核对主机密钥文件路径
```

将示例运行 ID 改为实际目录名。本包已有该次目录，上述命令会拒绝覆盖；试用可追加 `--dest 路径` 指向新的目录。采集脚本仅允许 `/var/lib/wifi-lab/runs/` 下的单个目录名，先取远程文件 SHA-256，再使用 `scp` 下载，再取一次远程摘要并与本地逐文件核对。核验成功才移入 `原始日志`；失败时保留 `.采集中-*` 暂存目录以便检查，不覆盖已有数据。只应采集最终状态已写入的运行，运行中或仍被修改的日志可能校验失败。

`--host` 和 `--known-hosts` 必须由用户提供；SSH 强制校验已通过可信渠道核对的主机密钥，不自动信任新密钥。不要将密码、公网登录信息或密钥文件提交到公开仓库。

## 整理基础验收

```powershell
python .\脚本\整理基础验收.py .\原始日志\运行目录名 --out .\整理结果\新的结果目录名
```

输出独立的 `运行记录.csv`、`终端汇总.csv`、`问题清单.csv` 和本地 `本地原始文件SHA256.json`。CSV 使用 UTF-8 BOM，便于 Excel 打开；每行包含原始文件引用。信号是仿真接口值；TCP 数值来自 `end.sum_received`，并保留窗口。ping 未采到时留空并记录问题，不将缺失视为 0。采集后生成的本地摘要用于之后核查本地文件，不能单独证明远端来源；远程一致性由采集步骤确认。

整理脚本只接受 `config.json` 的 `kind=smoke`，并按交接说明处理前两台终端的顺序 TCP 测试；对更多终端仅整理实际存在的关联与 ping。状态非 PASS、缺失或解析异常会写入问题清单并返回非零退出码；输出目录已存在、位于原始目录内或格式不是 smoke 会拒绝执行。请人工检查问题清单和原始文件，脚本不能证明正式实验的配置可比、采集完整或测量有效。

## 正式实验接入边界

采集脚本可按目录下载和校验已结束的运行，但 A、B、C 的日志格式和交付字段尚未取得，不能声称已适配其指标。拿到 04–06 号实际样本、工具版本和入口后再增加各组解析器，先与 08 号确认时间基准、窗口和字段；原始日志、缺测及失败运行均应保留。03 与 07 号复跑应使用审核后的入口，并记录原运行、版本、参数和关键指标差异。
