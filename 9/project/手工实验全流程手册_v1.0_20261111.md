# 9号手工实验全流程手册

版本：2026-11-11。适用：Windows PowerShell操作端 + 已部署Ubuntu实验机。

主流程已由wifi09实机跑通。以下数值摘自 `smoke_20261111T062720Z_3e2b4ph6`。目录、MAC地址、信号和速率会变化，不要求每次与示例相同。正式A/B/C复跑见附录，不能用基础验收代替。

## 1. 执行位置与准备

“本机”指Windows PowerShell；“远程”指SSH登录后的Ubuntu Bash。不要把Linux命令直接贴入PowerShell。无需重新安装公共平台。


预期：显示ssh/scp路径，网络检查含 `TcpTestSucceeded : True`。Ping失败但TCP成功仍可登录。TCP失败先检查网络、VPN、主机及安全组。

首次提示主机指纹，请与3号独立核对后接受。密码由本人输入，不回显是正常现象，不写入命令或录屏。成功出现Ubuntu欢迎信息及类似 `wifi09@localhost:~$` 的提示符。

## 4. 启动基础验收

【远程】

```bash
sudo -n /usr/local/sbin/wifi-lab 2 1,6
result=$?
printf 'EXIT_CODE=%s\n' "$result"
```

成功示例：

```text
本次日志目录 /var/lib/wifi-lab/runs/smoke_20261111T062720Z_3e2b4ph6
基础验收通过。
EXIT_CODE=0
```

参数含义：2终端，AP信道1/6。入口创建双AP、s1交换机与srv，完成关联、ping及逐终端3秒TCP测试，之后停止本轮网络。不需要手工启动iperf3或执行mn -c。一般等待几十秒；服务上限180秒，停止另有清理时间。

忙碌时提示“实验机正在运行另一组实验”，退出75。停止启动操作，切换离线证据；不要删除锁文件、杀进程或绕过锁。失败退出非0时保存本次日志。必须紧接命令保存 `$?`，否则得到的可能是后续ls命令退出码。

## 7. 核对ping

【远程】

```bash
cat "$run_dir/sta1-ping.txt"

```

sta1实测摘录：

```text
64 bytes from 10.44.0.100: icmp_seq=1 ttl=64 time=2.17 ms
64 bytes from 10.44.0.100: icmp_seq=2 ttl=64 time=0.584 ms
64 bytes from 10.44.0.100: icmp_seq=3 ttl=64 time=0.424 ms
```

sta2本次也是3发3收，平均0.883ms。三包只能验证短时连通，不能当作正式P95或长期丢包结论。不要在宿主机直接ping服务器私网地址替代节点内测试：节点在仿真命名空间内，入口结束后拓扑已停止。

## 8. 从JSON读取接收端吞吐

【远程】整块复制到Bash：

```bash
python3 - "$run_dir" <<'PY'
import json, pathlib, sys
for f in sorted(pathlib.Path(sys.argv[1]).glob('sta*-iperf3.json')):
    j = json.loads(f.read_text())
    if 'error' in j:
        print(f.name, 'ERROR', j['error'])
        continue
    r = j.get('end', {}).get('sum_received')
    if not r:
        print(f.name, 'MISSING end.sum_received')
        continue
    print(f.name, 'seconds=', round(r['seconds'], 3),
          'bytes=', r['bytes'],
          'Mbit/s=', round(r['bits_per_second'] / 1e6, 3))
PY
```

本次输出：

```text
sta1-iperf3.json seconds= 3.003 bytes= 13369344 Mbit/s= 35.619
sta2-iperf3.json seconds= 3.006 bytes= 13500416 Mbit/s= 35.923
```

两个测试顺序执行，不能相加声称并发总吞吐。ERROR、空JSON或缺字段应记录失败/缺测，不能填0当作有效样本。

## 10. 下载到本机

先退出远程：

```bash
exit
```

【本机 PowerShell】替换runName为本次目录：

```powershell
Set-Location 'D:\桌面\CNC-GR\9\project'
$runName = 'smoke_20261111T062720Z_3e2b4ph6'
$downloadRoot = Join-Path (Get-Location) ('manual_download_' + (Get-Date -Format 'yyyyMMdd_HHmmss'))
New-Item -ItemType Directory -Path $downloadRoot | Out-Null
scp -P 22 -r "wifi09@114.132.163.203:/var/lib/wifi-lab/runs/$runName" "$downloadRoot"
$runLocal = Join-Path $downloadRoot $runName
Get-ChildItem -LiteralPath $runLocal
Get-Content -Encoding utf8 (Join-Path $runLocal 'status.txt')
Get-Content -Encoding utf8 (Join-Path $runLocal 'config.json')
Get-ChildItem -LiteralPath $runLocal -File | Get-FileHash -Algorithm SHA256 |
    Export-Csv -Encoding utf8 -NoTypeInformation (Join-Path $downloadRoot 'download_sha256.csv')
```

预期：scp显示逐文件进度，本地目录存在且状态PASS。ssh使用小写-p，scp使用大写-P。本地哈希可冻结文件，若要证明与远程相同，再在远程执行 `sha256sum "$run_dir"/*` 并逐文件比较。

## 13. 正式A/B/C复跑附录

以下由3号或对应已授权负责人执行，9号不能直接执行额外sudo命令。先预约，再核对已部署路径、源码哈希与版本。路径不存在或权限不足时交3号，不自行改公共部署。

### A：并发与信道

在负责人批准的expA.py目录执行；脚本内部持公共锁，不再外套相同flock：

```bash
sudo python3 expA.py 4 1,6 04 wifi04
```

依次为终端数、信道、新重复号、操作者；04用于避免复用01—03。默认TCP60秒、UDP60秒，预热设置见源码。预期生成独立expA目录、配置、状态及各终端业务日志。正式矩阵固定1/6比较4/8/12终端，再固定12比较1/1和1/6，各至少3轮。9号3秒顺序验收不能代替A。

### B：移动与关联

上游交接的负责人命令：

```bash
cd /home/wifi05/expB-review
sudo flock -n /var/lib/wifi-lab/run.lock env MPLBACKEND=Agg python3 run_b.py ssf 4 formal
```

ssf换成llf执行另一策略。预期唯一目录包含observations下的samples.csv、iw.jsonl、ping.txt、clock.json以及决策和背景流日志。COLLECTED只表示采集结束，还须核对真实BSSID变化和背景流收包。不要把成功探测间隔等同于协议级切换时间。

本地实验B可写副本中分析：

```bash

```

预期生成/更新事件、时间线和汇总；不要覆盖冻结原始证据。

### C：FIFO与HTB

上游交接要求在已授权管理员终端执行；运行器内部持公共锁：

```bash
systemd-run --quiet --wait --pipe --collect \
  --property=PrivateTmp=yes --property=RuntimeMaxSec=300s \
  --property=TimeoutStopSec=30s \
  --setenv=MPLBACKEND=Agg --setenv=WIFI_OPERATOR=wifi06 \
  /usr/bin/python3 -IBu \
  /home/wifi06/expC_handoff_20261109/scripts/expc.py \
  baseline --run 4 --total-kbit 2000 --seconds 60
```

baseline换qos复跑保障组。预期生成独立目录，检查status.txt、run.log、metrics.json及队列计数。两组须同出口、同2000kbit/s总上限，不预设一定改善。以上正式入口是原负责人交接状态，9号未独立验证正式复跑。

本地wifi-qos可写副本复算：

## 14. 异常速查与结束清单

|现象|处理|
|---|---|
|SSH超时|检查TCP22、网络和主机状态|
|Permission denied|核对9号账号和密码，不循环重试|
|主机密钥变化|联系3号核对，不关闭校验绕过|
|sudo拒绝|确认完整固定入口并保存id、sudo -n -l输出|
|退出75|停止启动，使用离线材料，不清理他人进程|
|FAIL/非0|保存本次全部日志，不删失败样本|
|长期RUNNING/SSH断线|服务可能仍运行，联系3号，不自行mn -c|
|JSON错误或缺失|记录缺测，不填0冒充有效结果|
|Windows乱码|Get-Content指定-Encoding utf8，不改原始日志|

结束前：保存退出码和准确目录；核对状态/配置/关联/ping/iperf3/版本；下载归档并保存哈希；截图和录像对应同一运行；说明基础与正式结论边界；退出SSH。
