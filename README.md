# CNC-GR

针对研究生课程计算机与网络通信的课程小组汇报仓库。

## 目录结构

每位成员使用一个编号文件夹（`1/` 至 `10/`），各自的分工资料统一放在本人编号目录下：

```text
.
├── 1/
│   ├── project/   # 本人负责的数据、文档、代码与过程材料
│   └── ppt/       # 本人完成的汇报 PPT
├── 2/
│   ├── project/
│   └── ppt/
├── ...
└── 10/
    ├── project/
    └── ppt/
```

## 协作规范

1. **按编号归档**：每位成员只在自己编号的文件夹内新增和修改内容，不随意改动他人目录。
2. **资料放 `project/`**：数据、文档、代码、笔记、参考资料等过程性材料，统一放在本人编号下的 `project/` 中。
3. **PPT 放 `ppt/`**：完成的汇报 PPT（含最终版及必要素材）统一放在本人编号下的 `ppt/` 中。
4. **规范命名**：文件名建议采用“主题_版本_日期”的形式，避免使用“最终版”“最新版”等无法区分的名称；提交前删除无关的临时文件。
5. **提交前检查**：提交前先执行 `git status`，确认改动仅涉及本人目录；提交信息建议写明编号和内容，例如 `[3] 完成第三章数据整理`。
6. **同步后再推送**：推送前先执行 `git pull --rebase origin main`，及时处理冲突，避免覆盖他人提交；不要使用强制推送改写公共历史。
7. **大文件管理**：不要直接提交超大原始数据、视频或缓存文件；可将大文件存放在网盘，并在本人 `project/` 下保留说明和访问链接。
8. **保留占位文件**：目录中的 `.gitkeep` 仅用于让 Git 跟踪空文件夹，请勿删除。

完成个人材料后，请及时提交并推送到 `main` 分支，保持仓库内容最新。
